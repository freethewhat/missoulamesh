# Home Page Flow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lay out the home page as layout B: blurb beside a compact map, then the three join steps as a row of cards.

**Architecture:** Markup in `src/content/docs/index.mdx` (MDX with plain `<div>` wrappers), layout CSS in `src/styles/theme.css`, map sizing and caption style through the existing `compact` prop of `src/components/CoverageMap.astro`. Build tests in `tests/build/content-pages.test.js` pin the order and structure.

**Tech Stack:** Astro + Starlight, plain CSS grid, Node test runner, Playwright + axe.

**Spec:** `docs/superpowers/specs/2026-11-27-home-flow-design.md`

## Global Constraints

- WCAG 2.2 AA in light and dark; visible focus ring on every focusable element; no horizontal scroll at 320 px.
- No new third-party resources. The Repeaters page map stays full size (only `compact` changes size).
- Site copy: plain, short sentences. Step text and links stay as they are now.
- Branch `feat/home-join-columns` already holds uncommitted home-map work (`server/csp.js` comment, `tests/build/repeaters-page.test.js` Leaflet-route test, `CoverageMap` `compact` prop). Keep it.
- Do not commit or push unless Matt asks in the conversation.

## Review Focus

- Mid widths (about 800 to 1000 px): the blurb column must not get so narrow that the blurb wraps to one word per line. Stack the row below the breakpoint instead.
- Step cards with uneven text length: cards in one row should be the same height (grid stretch), numbers aligned at the top.
- Dark theme card background and border must still show the card edge (3:1 is not required for decoration, but text inside must pass 4.5:1).
- 320 px: three cards stack to one column, nothing overflows.
- Keyboard: focus order is blurb link, map, map zoom buttons, step links, full guide, contact link.

- [ ] **Step 4: CSS**

In `theme.css`, replace the `.mm-columns` rules with `.sl-markdown-content .mm-intro`: grid, one column by default; at `min-width: 50rem` use `grid-template-columns: 1fr 1.3fr`, `align-items: center`, `gap: 1.5rem 2.5rem`. Children get `margin-top: 0; min-width: 0`, first child of each column `margin-top: 0`.

Add `.mm-steps--cards`: grid, `grid-template-columns: repeat(auto-fit, minmax(min(100%, 13rem), 1fr))`, `gap: 1rem`. Each `li`: card (`background: var(--mm-paper)` or a token one step off the page, `border: 1px solid var(--mm-line)`, `border-radius: 0.5rem`, `padding: 1rem`, `margin: 0`). The number circle moves from the left gutter to the top of the card (`position: static`, `margin-bottom: 0.5rem`, `padding-inline-start: 0` on the li). Use existing color tokens only. Delete `.mm-steps--compact` rules if nothing else uses them (`grep -rn mm-steps--compact src`).

In `CoverageMap.astro`, set the compact map height to `clamp(240px, 38vh, 300px)` and `.mm-coverage-figure--compact { margin: 0; }`. Hide the empty slot space: render the `<slot />` only when `Astro.slots.has('default')`.
