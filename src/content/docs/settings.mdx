## Companion settings

A **companion** is the MeshCore device you pair with your phone.

- **Radio preset:** {settings.radio.presetName}
- **Path hash size:** {pathHashLabel(settings.pathHashMode)}. Find it in the app under network settings. (The **path hash** is a short ID each repeater adds to a message as it passes it on.)
- **Default region scope:** leave it blank for now. (A **region** keeps messages local. Setting one too early can cut you off from repeaters that do not have it.)

On a repeater, set the same path hash size with this command:

<Code code={pathHashCli(settings.pathHashMode)} lang="sh" />

## Channels

A **channel** is a group chat. Everyone on the same channel can read it.
