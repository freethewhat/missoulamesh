## What is MeshCore?

</div>
<div class="mm-intro-text">

**MeshCore** lets small radios pass text messages to each other with no cell service and no internet. Each message hops from radio to radio until it gets where it is going.

The Missoula mesh is a small network, built by neighbors. Every new radio makes it better.

The map shows where people have reached a repeater so far. Coverage changes with hills, weather, and your antenna.

See the [repeater list](/repeaters/) for details.
